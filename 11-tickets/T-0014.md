## Visual reference — Razorpay's own UI, not a generic fintech look

Don't hardcode brand tokens from memory or guesswork — Razorpay's public brand-assets page gates its real hex/type spec behind a request form, and a wrong guess presented with false confidence is worse than an honest placeholder. At build time:
- Pull 3–4 real screenshots of Razorpay's own dashboard / product marketing pages (their live site, or press screenshots) and lift the actual palette, spacing, and type from those pixels, not from this ticket's description.

## Amendment — 2026-08-28, added during the post-T-0006 spec revision

### Moved out of the build window entirely

**A dashboard is a video asset, not a code deliverable.** It only ever competed for build
days because it was sitting in the build window. The build window ends **Tue 1 Sep**; the
video window is **2–3 Sep** and is five minutes of screen time that has to be filled.

Building it after freeze costs **zero build days**, means it cannot touch any number, and
if it does not come together the fallback is matplotlib figures with nothing lost. The
original non-goal's own logic — *"a half-built one still costs credibility"* — was about a
UI competing with measurement work. After freeze it cannot compete with anything.

### The contradiction with `00-charter.md §7` is resolved, not left open

T-0017 amends §7 narrowly rather than reversing it:

> No production UI **inside the build window**. A read-only results viewer, built after
> code freeze and rendering only committed artifacts from `results/`, is permitted as a
> presentation asset.

The original wording and reasoning stay in the file, marked as amended and dated. The
"Reopens a locked non-goal" section above is therefore **no longer accurate** — the
non-goal was narrowed by ratified amendment, not reopened by instruction. `STATE.md`'s
open question on this is closed by T-0017.

### Hard constraint: the dashboard computes nothing

It reads `results/*.json` and `results/*.md` and renders them. **It must not calculate a
single metric.** The moment it computes, it becomes a second implementation of the metrics
that can silently disagree with the README — a credibility hole, not a feature. Any number
on screen must be traceable to a committed file, and the page should say which file.
