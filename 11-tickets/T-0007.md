## Build — `src/rakshak/decision/`
- `policy.py` — three-action policy: given a belief state + merchant cost parameters, return exactly one of `{PASS, REVIEW, HOLD}` and the expected cost of each option (FR-015, ADR-0005)
- `cost.py` — Bayes Minimum Risk: chosen action is the argmin of expected cost given a cost matrix and a calibrated posterior; savings score computed per Bahnsen et al. (2016) (FR-016)
- Global review-capacity constraint: total review time implied by all REVIEW actions must not exceed the K analyst-hours budget for the period; report which constraint is binding (FR-017, ADR-0005)

## Done when
- Unit test against hand-computed values on a 2-merchant fixture (FR-016 acceptance)
- Policy returns exactly one action + expected cost of each alternative, for a boundary-crossing test case
- Capacity constraint holds across the whole frontier, and the binding constraint is reported, not silently dropped
