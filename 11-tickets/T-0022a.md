## Why this ticket exists

The generator models every merchant as a fully independent stochastic process. Nothing in this repo can currently test what happens when something hits many merchants at once — a demand surge, an MDR/regulatory change, a payment-rail outage. Without that scenario, the project's own central cost claim ("blunt global thresholds freeze honest merchants") is asserted, never measured.

## Build

- Add `--shock-day` (repeatable, day-of-horizon integers) and `--shock-magnitude` (multiplier) to `generate.py`'s CLI, via `rakshak.cli.base_parser`.
- On a shock day, apply the magnitude multiplier to per-merchant daily transaction volume and mean amount, identically across every merchant regardless of typology or segment.
- Write output to a new `SYNTHETIC_SHOCK_DIR` (`data/synthetic_shock/`), mirroring `SYNTHETIC_DIR`'s two-file layout (`transactions.parquet`, `state_paths.parquet`). **Never write to `data/synthetic/`.**
- Reuse `SPLIT_DAY_BOUNDS` / `MERCHANT_GROUP_CYCLE` unmodified — this is a new dataset scored the same way, not a new split design.
- The shock introduces no new latent state: `state_paths.parquet` must show HEALTHY merchants staying HEALTHY through a shock day. This is the point of the test — ground truth says nothing changed, so any model flagging a shocked-but-healthy merchant is by construction a false positive.

## Done when

- `python -m rakshak.generator.generate --shock-day <D> --shock-magnitude <M> --seed 42` produces `data/synthetic_shock/{transactions,state_paths}.parquet` and leaves `data/synthetic/` byte-identical to before this ticket.
- Determinism test: same seed + same shock args → identical output hash (mirrors the existing unshocked determinism test).
- Invariant test: no merchant's `state_paths.parquet` entry changes state across a shock day due to the shock alone.
- `python -m pytest` and `python -m ruff check src tests` still pass.

## What this ticket must NOT do

- Must not touch `SPLIT_DAY_BOUNDS`, `MERCHANT_GROUP_CYCLE`, or any file under `results/`.
- Must not modify `data/synthetic/` or any code path that reads it by default.
- Must not add a new latent state or otherwise make the shock visible in ground truth.
