## Amendment — 2026-08-28, added during the post-T-0006 spec revision

### Promoted SHOULD → MUST

`CLAUDE.md` mandates a verbatim framing sentence for every results table, the README and
the video:

> *"The decision layer is additionally validated on BAF (Feedzai, NeurIPS 2022), a public
> benchmark derived from real bank data."*

**The repo cannot currently back that sentence.** `results/summary.md` already prints it
with an embarrassed parenthetical — *"(BAF validation lands in T-0012 and is absent
below.)"* Cutting this ticket therefore does not cost a nice-to-have appendix; it forces
that sentence to be struck from `CLAUDE.md`, the README and the video script. That is
editing the project's own honesty statement downward to fit a schedule.

FR-021 is promoted to MUST in T-0017 for this reason.

### Why it won the last slot over T-0016

With one slot remaining before the 1 Sep freeze, **validating on real data beats
simulating real data better.** This ticket is the only point in the entire repo where a
model touches real-world-derived data. T-0016 would leave everything synthetic — just
synthetic with better-sourced parameters — while invalidating the K1 analysis, the 0.404
oracle ceiling and every baseline row on the final day.

### Now depends on T-0015

T-0015 builds the downloader, manifest and licence verification. This ticket no longer
fetches BAF itself; it consumes T-0015's `data/external/` artifact and runs the T-0007b
decision layer against BAF's **native** temporal split. Cost dropped accordingly.
