# T-110 — Persona/typology config dataclasses + `configs/scenario_v2.yaml` loader

**Status:** done · **Lane:** A · **Session:** 2026-08-31

## Built
- `src/rakshak/generator/config.py` — fourteen frozen dataclasses covering the whole
  parameter surface, plus a recursive loader (`_build`/`_coerce`) that constructs any of
  them from YAML and names the **dotted field path** on every error.
- `configs/scenario_v2.yaml` — ~560 lines, every value named and commented. Charter §10's
  four confirmed numbers are in it verbatim (10,000 x 180, prevalence 0.0147, K = 50 per
  10,000, target Fano 12.25) and asserted by name in the test.
- `tests/unit/test_config.py` — 19 cases. Shares to 1.0 +/- 1e-9, invalid configs naming
  the field, `prevalence = 0` legal (gate G5 runs there), K scaling with population.

## Surprised
**Every field is required, and that was not the plan.** The first cut gave the dataclasses
sensible defaults. Halfway through the YAML it became obvious that a default *is* a magic
number with a nicer name: nothing forces the file to state it, nothing shows it in a diff,
and CLAUDE.md's "no magic numbers in `src/`" is satisfied on a technicality while the real
parameter surface is invisible. Making every field required cost about twenty minutes of
YAML and turned the scenario file into an actual specification. The unknown-key check
turned out to matter more than the missing-key check — a renamed parameter that the YAML
still sets under its old name fails *nothing* otherwise.

The second surprise was the generic loader. Fourteen hand-written `from_dict` methods was
the obvious shape and would have been fourteen places to silently drop a field, because a
dropped field still constructs. `get_type_hints` plus 40 lines does the whole thing and
gives better errors.

## Broke
Nothing on the first run of the tests, which is itself suspicious enough to mention —
`test_config.py` passed 19/19 first time. The loader was exercised hard immediately
afterwards by T-111..T-115, which added eight more required fields
(`shape_count`, `shape_jitter`, `vanish_intensity`, `window_days`,
`accelerated_prob_per_urgency`, `declaration_error_sigma`, `max_vintage_months`,
`min_true_loss_inr`) and one removal (`intl_share`, which duplicated the `intl_card` entry
of `instrument_mix` and could disagree with it). Each of those was caught by the
missing-key error naming the exact path, which is the loader doing its job.
