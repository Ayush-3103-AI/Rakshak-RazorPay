## Surprised
**`make` is not installed on this machine.** The Makefile is still the source of truth and CI
runs it on Linux, but no local command could execute it. Rather than keep two command lists in
sync by discipline, `make.ps1` reads the Makefile, expands `$(VAR)`, resolves prerequisites
depth-first, and runs the recipe lines. It is the smallest thing that makes the two agree by
construction instead of by attention.

**`make all` is deliberately `lint test` today, not the full pipeline.** The chain in CLAUDE.md
names targets whose code does not exist yet, so a `clean-clone` job running it would be red
from ticket one — and a CI that is always red teaches everyone to ignore CI. Instead `all` grows
a stage as each lane lands; the Makefile carries a comment naming which ticket appends which
stage. The job is therefore always green *and* always testing everything that exists.
